# Píldora: Introducción a SASS
Píldora formativa sobre SASS presentada en el Bootcamp de FemCoders F5.

## 📎 Presentación
Ver presentación en Canva: https://canva.link/2jb6tkz22vvc25k

## Conceptos cubiertos
- Qué es SASS
- Key concepts
- Variables (`$`)
- Nesting
- Mixins (`@mixin` / `@include`)

## Cómo usarlo
1. Clona el repositorio
2. Instala la extensión **Live Sass Compiler** en VSCode
3. Haz clic en **"Watch Sass"** en la barra inferior
